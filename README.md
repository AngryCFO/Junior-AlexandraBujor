# Отчет о тестировании вкладки "Плеер" в ПО УФ пеленгатора С2

В данном отчете представлены результаты тестирования вкладки "Плеер" на соответствие требованиям. На основании предоставленных материалов выявлен ряд несоответствий между реализацией и требованиями к программному обеспечению.

## Выявленные проблемы

### Проблема №1: Отсутствие интерактива кнопок "Воспроизведение", "Стоп", "Пауза"

**Краткое описание проблемы**: На вкладке "Плеер" отсутствует при нажатии не меняют окраску кнопки "Воспроизведение", "Стоп", "Пауза" которая должна темнеть или светлеть согласно требованиям.

**Подробное описание проблемы**: В соответствии с требованиями, указанными в разделе 2.2 документации, в интерфейсе плеера должны изменять цвет при активации следующие кнопки: "Воспроизведение", "Стоп", "Пауза". На скриншоте видно, что присутствуют указанные кнопки, но отсутствует изменение их окраски при их активации.

**Сценарий**: 
1. Открыть вкладку "Плеер" 
2. Визуально проверить наличие всех требуемых кнопок управления
3. Понажимать на кнопки "Воспроизведение", "Стоп", "Пауза"
4. Зафиксировать отсутствие изменения их окраса в интерфейсе

### Проблема №2: Несоответствие формата даты в имени файла

**Краткое описание проблемы**: Формат даты в воспроизводимом файле не соответствует требованиям.

**Подробное описание проблемы**: В документации (раздел 2.2) указано, что название файла должно иметь формат "год.месяц.день_000". На скриншоте видно, что в интерфейсе отображается дата "01.01.1900", а не реальная дата создания файла. Кроме того, формат файла, видимый в рабочем каталоге, также не соответствует указанному в требованиях формату.

**Сценарий**: 
1. Открыть вкладку "Плеер"
2. Загрузить видеофайл для воспроизведения
3. Проверить формат отображаемой даты файла

### Проблема №3: Некорректные значения координат

**Краткое описание проблемы**: В интерфейсе плеера отображаются нулевые координаты "N0.0000 E0.0000".

**Подробное описание проблемы**: На скриншоте видны координаты "N0.0000 E0.0000", которые с высокой вероятностью являются значениями по умолчанию. Хотя в требованиях напрямую не указана необходимость отображения координат, их нулевые значения указывают на проблему с получением или отображением метаданных файла.

**Сценарий**: 
1. Открыть вкладку "Плеер"
2. Загрузить видеофайл
3. Проверить отображаемые координаты

### Проблема №4: Отсутствие действий при нажатии на кнопку "Загрузка файлов"

**Краткое описание проблемы**: При нажатии на кнопку "Загрузка файлов" ничего не происходит.

**Подробное описание проблемы**: Согласно требованиям из раздела 3.1, При нажатии на кнопку "Загрузка файлов" открывается диалог «Загрузка файлов», но по факту ничего не происходит.

**Сценарий**: 
1. Открыть приложение
2. Перейти на вкладку "Плеер"
3. Нажать на кнопку "Загрузка файлов"

### Проблема №5: Отсутствие действий при нажатии на кнопку "Корзина"

**Краткое описание проблемы**: При нажатии на кнопку "Корзина" ничего не происходит.

**Подробное описание проблемы**: Согласно требованиям из раздела 3.2, При нажатии на кнопку "Корзина" открывается окно с выбором файлов для удаления, но по факту ничего не происходит.

**Сценарий**: 
1. Открыть приложение
2. Перейти на вкладку "Плеер"
3. Нажать на кнопку "Корзина"
   
### Проблема №6: Некорректное отображение времени воспроизведения

**Краткое описание проблемы**: В интерфейсе плеера отображается время "00:00:00".

**Подробное описание проблемы**: Временная метка "00:00:00" на скриншоте указывает на то, что либо воспроизведение не начато, либо имеются проблемы с отображением времени воспроизведения. Для работающего плеера ожидается корректное отображение текущего времени воспроизведения.

**Сценарий**: 
1. Открыть вкладку "Плеер"
2. Загрузить и начать воспроизведение видеофайла
3. Проверить корректность отображения времени воспроизведения

### Проблема №7: Ошибка при сворачивании окна программы

**Краткое описание проблемы**: Программв крашится.

**Подробное описание проблемы**: При сворачивании окна программы появляется ошибка "Не удается создать директорию".
![image](https://github.com/user-attachments/assets/5cae0dec-e399-4c96-b767-4a795ff35001)

**Сценарий**: 
1. Открыть вкладку "Плеер"
2. Свернуть окно программы

## Заключение

Выявленные проблемы указывают на существенные несоответствия между реализацией вкладки "Плеер" и документацией требований. Основные несоответствия касаются отсутствия требуемых характеристик элементов интерфейса (окрасу кнопки "Воспроизведение", "Стоп", "Пауза";отсутствие действий после активации кнопок "Загрузка файлов" и "Корзина"),  некорректного отображения метаданных файла (формат даты, координаты, время воспроизведения) и краш программы (при попытке свернуть окно).
